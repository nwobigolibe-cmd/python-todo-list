## Overview

A simple command-line to-do list application written in Python. It allows users to manage a list of tasks by adding new items, removing existing ones, and viewing their current tasks.

## Features

- Add tasks to the list.
- Prevent duplicate tasks from being added.
- Remove existing tasks.
- Display all current tasks with numbered entries.
- Handle empty lists and invalid menu selections.
- Exit the application through a menu option.

## Technologies

- Python 3

## Concepts Demonstrated

- Functions and modular programming
- Lists and list manipulation
- Loops and conditional statements
- User input and output
- String methods and formatting
- Basic input validation

## How to Run

1. Ensure Python 3 is installed.
2. Download or clone this repository.
3. Open a terminal in the project directory.
4. Run:

```bash
python main.py
```

Depending on your system, you may need to use `python3 main.py`.
